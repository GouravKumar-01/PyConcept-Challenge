Lists

A list stores many values in order. Each item has an index, and counting starts at 0, not 1.

Recursion

    
Recursion is a function that calls itself on a smaller problem until it reaches a simple base case. Watch the call stack grow, then collapse as answers return.

    
def factorial(n):
    if n == 1:
        return 1          # base case
    return n * factorial(n - 1)
